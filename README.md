# Bijli Bill (Android app)

1. Create a new GitHub repository and upload everything in this folder (keep the .github folder).
2. Open the Actions tab and wait for "Build APK" to finish (about 4 to 6 minutes).
3. Open the finished run, download the "BijliBill-apk" file at the bottom, unzip it.
4. Copy app-debug.apk to your phone and install it (allow "Install unknown apps" when asked).

To change the app later, edit www/index.html and commit. The Actions tab builds a new APK.
Bill amounts you change inside the app are saved on the phone itself.
